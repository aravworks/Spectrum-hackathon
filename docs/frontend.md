# Frontend

## Applications
One TypeScript codebase can expose role-specific experiences:
1. Consumer PWA
2. Collector PWA
3. Admin web dashboard
4. Research/analytics portal

## Consumer screens
- Landing
- Register/Login
- Home
- Report waste
- Pickup request
- My reports
- Complaint details/timeline
- My footprint
- Awareness
- Waste reality
- Marketplace
- My earnings
- Profile/settings

## Collector screens
- Today's jobs
- Map/route
- Job details
- Start pickup
- Record actual weight
- Upload proof
- Complete job
- Route history

## Admin screens
- City dashboard
- Live operations map
- Reports
- Pickups
- Dispatch/route planner
- Hotspots
- Dump candidates
- Users/collectors
- Payments/reconciliation
- Awareness CMS
- Marketplace moderation
- Research lab
- Environmental metrics
- Audit logs

## UX requirements
- mobile-first
- low-bandwidth friendly
- accessible labels
- multilingual-ready
- clear uncertainty labels on estimates
- no dark patterns
- explicit consent for location/media
- map fallback to list view
