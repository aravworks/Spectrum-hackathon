# Project Charter

## Vision
Build a trustworthy digital layer for waste collection, recycling, environmental awareness and evidence-based planning.

## Initial deployment assumption
The project brief assumes ~185,000 tonnes/day of waste generation nationally. This is a planning assumption for architecture sizing; replace it with a cited official figure before making public claims.

## MVP success criteria
- Consumer can register and report a waste issue.
- Collector can receive and complete a job.
- Admin can monitor city operations.
- Verified weight can drive a transparent payout ledger.
- User can see a traceable complaint lifecycle.
- System can generate city-level operational metrics.
- GIS map can display reports and verified hotspots.
- Environmental estimates expose methodology and uncertainty.

## Explicit non-goals for MVP
- Automatic nationwide satellite dump verification.
- Guaranteed real-world methane measurement without sensors.
- Unverified claims of exact carbon savings.
- Fully autonomous routing without human/operational constraints.
- Direct government system integration unless an authorized API exists.
